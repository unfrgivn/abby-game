## Iteration Modifiers

Add these if outputs need adjustment:

| Problem | Add to prompt |
|---------|---------------|
| Too detailed | "low detail, large shapes, no microdetail" |
| Too realistic | "toy-like, cartoon 3D, no realism" |
| Too noisy/busy | "clean, flat colors, minimal texture" |
| Hard to read | "gameplay readable from above, clear silhouettes" |
| Too dark | "soft sunlight, calm afternoon, bright but calm" |
