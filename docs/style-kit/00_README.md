# Wilds of Cloverhollow — Art & Feel Starter Kit (v0)

This kit helps you generate consistent concept art and assets for a **Lil Gator-inspired, top-down 3D** cozy adventure. It is written to be **engine-agnostic**, with implementation notes aligned to **Godot 4**.

## What you get
- A small art bible with hard rules (palette, shapes, materials, lighting, UI, animation feel)
- Asset lists for a tiny vertical slice and for scaling the world
- Camera/controls defaults tuned for a fixed-tilt top-down 3D “living diorama”
- A prompt pack you can paste into image generators to get consistent results

## Folder contents
- `01_ART_DIRECTION.md` — the rules; use this like a contract
- `02_CAMERA_CONTROLS.md` — camera, framing, touch controls
- `03_ASSET_SPEC.md` — scale, poly budgets, materials, naming conventions
- `04_WORLD_KIT.md` — biomes, landmarks, modular kit, dressing rules
- `05_UI_STYLE.md` — sticker UI, icons, typography guidance
- `06_ANIMATION_FEEL.md` — bouncy motion rules and timings
- `07_PROMPT_PACK.md` — prompt templates + ready-to-paste prompts
- `08_BATTLE_UI_AND_STICKERS.md` — battle UI composition + sticker loadout rules
- `PALETTE.json / PALETTE.csv` — your single source of truth

## How to use this quickly
1. Build the tiny vertical slice in `04_WORLD_KIT.md` first.
2. Use `07_PROMPT_PACK.md` to generate: player concept, 1 zone concept, prop sheets, sticker UI set.
3. Enforce the palette and “chunky shapes” rule before adding any new complexity.
